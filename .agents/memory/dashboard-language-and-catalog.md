Keep the five bottom tabs ordered Accueil, Produits, Partage, Équipe, Compte. “Produits” opens the combined catalog and owned-products screen, with offers first and purchased positions in the second tab. “Partage” leads to invitation/referral features and “Équipe” to team statistics. Use actual active catalog products and FCFA prices and earnings; screenshot examples are not product data.

**Why:** The user specified French navigation, page-name-only titles, English metadata descriptions, real FCFA catalog data, that browser chrome remain untouched, and a product-screen reference with offers and owned products in one tabbed screen.

**How to apply:** Localize dashboard banners, labels, actions, and dialogs. Keep titles short and route-specific; use English for standard, Open Graph, and Twitter meta descriptions. Preserve the live product API and purchase flow; never replace actual catalog data with visual placeholders. Keep the combined product screen backed by the real offer and user-position APIs.
