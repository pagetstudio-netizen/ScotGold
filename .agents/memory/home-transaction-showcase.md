---
name: Home transaction showcase
description: Product requirements for the illustrative transaction feed on the Scotgold homepage.
---

The homepage transaction showcase uses fictional, varied entries in English and FCFA, scrolling within its own card. Keep it visibly marked as a demo and separate from live balances, the ledger, and real customer activity.

**Why:** The user requested fictional transaction examples on the homepage, and visitors should not mistake them for real account activity.

**How to apply:** Keep the feed sample-only, use masked fictional identifiers, preserve the demo disclosure, and never use these entries to calculate balances or create transactions.
